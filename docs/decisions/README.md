# Decisions

Architecture decision records. Most are inherited from the
[Epic Stack](https://github.com/epicweb-dev/epic-stack), which this app was built
on, and are kept because they still explain why the code looks the way it does.
The gaps in the numbering were records describing subsystems this app removed —
authentication, Prisma, SQLite, Fly.io, hosted image storage — which no longer
apply to anything here.

Each record is a snapshot of its date, so an older one may name a tool that has
since been replaced. Where that happens the record is history, not instruction;
the [top-level docs](../README.md) describe the current state.

Use [`000-template.md`](./000-template.md) for new records.
